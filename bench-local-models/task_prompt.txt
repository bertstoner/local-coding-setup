Create a file named lru_cache.py implementing a class LRUCache with this exact interface:

    class LRUCache:
        def __init__(self, capacity: int): ...
        def get(self, key: int) -> int: ...   # returns -1 if key not found
        def put(self, key: int, value: int) -> None: ...

Both get and put must run in O(1) time. Using an OrderedDict is fine.
When capacity is exceeded, evict the least recently used key.
Accessing a key via get() or put() counts as using it (moves it to most-recently-used).

Also add a `if __name__ == "__main__":` block at the bottom of the file that
runs this exact sequence and prints "ALL PASSED" if every assertion succeeds:

    cache = LRUCache(2)
    cache.put(1, 1)
    cache.put(2, 2)
    assert cache.get(1) == 1
    cache.put(3, 3)          # evicts key 2
    assert cache.get(2) == -1
    cache.put(4, 4)          # evicts key 1
    assert cache.get(1) == -1
    assert cache.get(3) == 3
    assert cache.get(4) == 4
    print("ALL PASSED")
